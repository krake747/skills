# skills

An extension to [mattpocock/skills](https://github.com/mattpocock/skills). I run that full set; this
repo only holds skills that fill gaps I encounter in my day-to-day work and it does not cover.

```bash
npx skills add krake747/skills
```

## Workflow

Matt's loop covers the whole lifecycle: grill-me or grill-with-docs to align, to-spec to write the
spec, to-tickets to break it up, implement to build, code-review to check the diff. These skills
plug into that loop where it has gaps, detailed below.

## Skills

- **[plan-first](plan-first/SKILL.md).** Plan before code. A lightweight 20-line plan for small
  tasks, complementing the grilling interview.
- **[humanize](humanize/SKILL.md).** Rewrite text so it reads like a person wrote it. Complements
  writing-for-agents, which serves agents, not humans.
- **[scaffold](scaffold/SKILL.md).** Match the codebase's existing patterns when writing new code.
  Complements codebase-design and implement.
- **[debrief](debrief/SKILL.md).** After a long session, list the decisions the agent made on its
  own judgment. Complements code-review, which reviews the diff rather than the session.

# Report Writer

Write the report the reader needs. Open with the headline, then the numbers, then the risks.

## Headlines

Headlines carry the verdict in under ten words. Never bury the verdict in the third paragraph. A
headline that needs its paragraph to make sense is not a headline.

## Numbers

Every number earns its place. Cite the source beside the figure. Round to two significant digits
unless precision changes the decision. A table with more than five columns belongs in an appendix.

## Risks

Name the risk, the owner, and the mitigation in one line each. Never list a risk with no owner. An
unowned risk is a wish. Review risks every cycle and drop the ones that expired.

## Tone

Short sentences. Active voice. No throat clearing. Read the draft aloud once; any sentence you
stumble on gets rewritten. The reader's time costs more than yours.

## Formatting

One idea per paragraph. Headers every three paragraphs or the reader is lost. Bold sparingly; bold
on every key term means nothing is key. Lists for options, prose for narrative.

## Delivery

Send the draft, ask for one round of notes, apply them, send again. Never send a third draft without
asking whether the report still matters. Stale reports rot twice as fast.

## Archive

File the final report where the next reader looks first. Name it by date and topic. Link it from the
index. An unlinked report does not exist.

## Follow-ups

Track every follow-up to done or explicitly dropped. A follow-up with no owner rots. Review the list
weekly and say out loud which items died and why.

# Ledger Kit

Ledger Kit is a powerful, flexible, and production-ready toolkit for turning transaction files into
useful reports. It is designed to make financial data workflows fast and painless for every team.

## Install

```bash
pnpm install
```

## Run locally

```bash
pnpm dev
```

Then open http://localhost:4173.

## What it does

Ledger Kit reads transaction files and produces monthly reports. More integrations and dashboards
are planned.
